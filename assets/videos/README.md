# 🎬 Birthday Videos Directory

Place your custom birthday memory video files here!

### Recommended File Names & Formats:
- `memory1.mp4` — Stage 1 video reward
- `memory2.mp4` — Stage 2 video reward
- `memory3.mp4` — Stage 3 video reward
- `memory4.mp4` — Stage 4 video reward

### Supported Formats:
- `.mp4` (H.264 video codec recommended for universal browser compatibility on iOS, Android, Mac, and Windows)
- `.webm`

### Using YouTube or Online Video URLs Instead:
You can also use YouTube links (e.g. `https://www.youtube.com/watch?v=YOUR_VIDEO_ID`) or cloud storage URLs directly in `config.js`!

### What happens if a video file is missing?
The website has built-in graceful error handling! If a video hasn't been placed yet or fails to load, it automatically displays an animated Polaroid memory photo preview with particles and unlocks the continue button so your friend will never get stuck or see a broken screen.
